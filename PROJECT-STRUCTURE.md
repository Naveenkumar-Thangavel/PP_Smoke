## Key Files Explained

### 1. `.github/workflows/playwright-report.yml` ⭐

**Purpose**: GitHub Actions workflow that:
- Runs tests automatically on push/PR
- Generates Allure reports
- Publishes reports to GitHub Pages

**Contains 2 jobs**:
- `test`: Run Playwright tests and generate report
- `deploy-report`: Publish report to GitHub Pages

**When it runs**:
- On push to `main` branch
- On PR to `main` branch
- Manual trigger via workflow_dispatch

---

### 2. `tests/auth.setup.js` ⭐

**Purpose**: Authentication setup that runs once before all other tests

**What it does**:
- Loads credentials from environment
- Performs login (handles dynamic auth path)
- Saves authentication state to `playwright/.auth/user.json`

**Critical for**: All other tests depend on this

**Configuration** (in `playwright.config.js`):
```javascript
projects: [
  { name: 'setup', testMatch: /auth\.setup\.js/ },  // Runs first
  {
    name: 'chromium',
    testIgnore: /auth\.setup\.js/,                  // Other tests
    dependencies: ['setup'],                        // Depend on auth.setup
  },
]
```

---

### 3. `playwright.config.js` ⭐

**Key Configuration**:

```javascript
testDir: './tests'                    // Where tests are located
timeout: 90_000                       // Per-test timeout: 90 seconds
expect: { timeout: 15_000 }           // Assertion timeout: 15 seconds
fullyParallel: false                  // Run tests sequentially
workers: 1                            // Single worker

reporter: [
  ['list'],                           // Console output
  ['allure-playwright', {             // Allure report
    resultsDir: 'allure-results'
  }],
]

use: {
  baseURL: process.env.BASE_URL       // From .env file
  trace: 'retain-on-failure'          // Save trace on failure
  screenshot: 'only-on-failure'       // Screenshot on failure
  video: 'retain-on-failure'          // Video on failure
}
```

---

### 4. `package.json` ⭐

**npm Scripts**:

```json
{
  "scripts": {
    "test:smoke": "playwright test",
    "allure:clean": "rimraf allure-results allure-report",
    "allure:generate": "allure generate allure-results --clean -o allure-report",
    "allure:open": "allure open allure-report",
    "test:smoke:report": "npm run test:smoke && npm run allure:generate && npm run allure:open"
  }
}
```

**Dependencies**:
- `@playwright/test` - Testing framework
- `allure-playwright` - Allure reporter for Playwright
- `allure-commandline` - Allure CLI to generate reports
- `dotenv` - Load .env variables

    ├─→ saves auth state to: playwright/.auth/user.json
    │
    └─→ used by: LoginPage.spec.js, HomePage.spec.js, UsersPage.spec.js, Modules.spec.js

    │
    ├─→ use: Page Object Model (pages/*.js)

    │
    └─→ consumed by: npm run allure:generate
        │

.env
    │
    └─→ used by: playwright.config.js (process.env)
        │
        └─→ used by: auth.setup.js, utils/env.js

## Git Ignore Structure

**Committed to Git** (in repository):
- Source code: `pages/`, `tests/`, `utils/`
- Configuration: `playwright.config.js`, `package.json`, `package-lock.json`
- Documentation: `README.md`, `GITHUB-PAGES-*.md`, `TROUBLESHOOTING.md`
- GitHub Actions: `.github/workflows/`
- Environment template: `.env.example`
- Git config: `.gitignore`

**NOT Committed** (in .gitignore):
- Environment file: `.env` (contains credentials)
- Dependencies: `node_modules/`
- Test results: `allure-results/`, `test-results/`
- Generated reports: `allure-report/`
- Browser cache: `playwright/.cache/`
- Saved auth: `playwright/.auth/user.json` (regenerated on each run)

## Adding New Tests

When creating new test files:

```
1. Create page object: pages/NewPage.js
   - Define selectors
   - Create action methods
   - Export class

2. Create test spec: tests/NewPage.spec.js
   - Import page object
   - Import auth setup fixture (if needed)
   - Write tests using page object
   - Use Allure steps/annotations

3. Tests automatically:
   - Run in CI when pushed to main
   - Generate results in allure-results/
   - Included in final report
```

## Updating Configuration

### To change test timeout:
- Edit `playwright.config.js`
- Update `timeout: 90_000` value
- Re-run: `npm run test:smoke`

### To change Allure report directory:
- Edit `playwright.config.js`
- Update `resultsDir: 'allure-results'` in reporter config
- Update scripts in `package.json` if needed

### To add environment variables:
- Add to `.env.example`
- Update `utils/env.js` to export new variable
- Use in tests via `require('./utils/env.js')`

### To change GitHub Actions trigger:
- Edit `.github/workflows/playwright-report.yml`
- Update `on:` section
- Commit and push to main
